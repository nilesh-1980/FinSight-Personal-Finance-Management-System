#  FinSight – Personal Finance Management System

FinSight is a full-stack personal finance and budget management system built using Spring Boot, React.js, and MySQL. It helps users manage income, expenses, budgets, savings goals, recurring transactions, financial reports, and smart insights through an interactive dashboard.

##  Features

- User Registration and Login
- JWT Authentication
- Forgot Password with Email OTP
- Income Management
- Expense Management
- Budget Management
- Savings Goal Tracker
- Recurring Transactions
- Category Wise Expense Analysis
- Pie Chart and Bar Chart Dashboard
- Smart Financial Insights
- Budget Alerts and Notifications
- Profile Page with Photo Upload
- Change Password
- PDF Report Download
- Admin Dashboard
- Dark / Light Theme

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Axios
- React Router DOM
- Recharts
- CSS

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- JWT
- JavaMailSender
- iText PDF

### Database
- MySQL
